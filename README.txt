SAYUUUUU — ROMANTIC PROPOSAL WEBSITE
====================================

WHAT'S INCLUDED
- index.html: the page content and messages
- style.css: colors, layout, animations, mobile styling
- script.js: envelope interaction, floating hearts, proposal button
- photos/: put your own photos here

OPEN IT LOCALLY
1. Open this folder in VS Code.
2. Open index.html.
3. If you have the Live Server extension, right-click index.html and choose
   "Open with Live Server". Or simply open index.html in your browser.
4. Test the envelope, scroll, and proposal button.

ADD YOUR OWN PHOTOS
1. Copy your chosen pictures into the photos folder, for example:
   photos/us-1.jpg
   photos/us-2.jpg
   photos/us-3.jpg
2. In index.html, find each <div class="photo-placeholder">...</div>.
3. Replace that whole placeholder div with an image tag, for example:
   <img src="photos/us-1.jpg" alt="A favourite memory of us">
4. Change the caption text directly below it in the matching <figcaption>.
5. Repeat for the other photos.

PERSONALIZE YOUR MESSAGE
Open index.html and edit:
- "TO MY SAYUUUUU"
- The paragraphs inside the note-card
- The three photo captions
- The final message and "Will you be mine forever?"

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com
2. Create a NEW PUBLIC repository, for example: sayuu-proposal
3. Upload index.html, style.css, script.js, README.txt and the photos folder
   (upload your own final photos only after you're comfortable with them being
   accessible to anyone who can access the public site).
4. In the repository, open Settings → Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait a few minutes. GitHub will show the published site link in Settings → Pages.
8. Open the link on your phone and test it before sending it to her.

PRIVACY NOTE
GitHub Pages sites are public websites. Anyone who gets the link may open it,
and the photos/files in a public repository can be viewed or downloaded. Do not
include private or intimate images. If you need stronger access control, use a
hosting service with access protection instead of a public GitHub Pages site.

NO SERVER REQUIRED
This is a static website. It uses only HTML, CSS and browser-side JavaScript.
Google Fonts is an optional external font; the page falls back to system fonts
if it cannot load.
